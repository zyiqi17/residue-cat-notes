e^z 的週期性、Log z 與分支切割、i^i、為什麼 sin z 無界。

本章目錄

    性質

    複指數函數 e^z

    定義：e^z = e^{x}(cos y + i sin y)，z = x + iy。

    性質：e^z 是整函數且 (e^z)' = e^z；|e^z| = e^x；arg(e^z) = y + 2kπ。

    e^z 永遠不為 0。

    週期性：e^{z + 2πi} = e^z，週期是 2πi（實數的 e^x 沒有週期）。因此 e^z 不是一對一，這也是複數對數會多值的原因。

    例：e^z = −1 的所有解為 z = (2k + 1)πi。

    複數對數 log z 與主值 Log z、分支切割

    log z = ln|z| + i arg z（z ≠ 0），是多值函數，任兩值相差 2πi 的整數倍。

    主值：Log z = ln|z| + i Arg z，−π < Arg z ≤ π。

    例：Log(−1) = iπ，Log(i) = iπ/2，log(1) = 2kπi。

    解析性：Log z 在 ℂ 去掉負實軸與 0（也就是 ℂ \ (−∞, 0]）上解析，且 (Log z)' = 1/z。被拿掉的射線 (−∞, 0] 叫做分支切割（branch cut）。

    ⚠️ 常見錯誤Log(z₁z₂) = Log z₁ + Log z₂ 一般不成立。例：Log((−1)(−1)) = Log 1 = 0，但 Log(−1) + Log(−1) = 2πi。

    複數次方 z^c 與 i^i

    定義：z^c = e^{c log z}（z ≠ 0），因為 log z 多值，所以 z^c 一般也是多值。主值為 e^{c Log z}。

    例：i^i = e^{i log i} = e^{i · i(π/2 + 2kπ)} = e^{−π/2 − 2kπ}，k 為整數。

    所以 i^i 的值全部是「正實數」，主值是 e^{−π/2} ≈ 0.2079。

    若 c 是整數，z^c 單值；若 c = 1/n，恰好有 n 個不同值（就是 n 次方根）；若 c 是無理數或非實數，有無窮多個值。

    性質

    複三角函數與雙曲函數

    定義：sin z = (e^{iz} − e^{−iz})/(2i)，cos z = (e^{iz} + e^{−iz})/2，都是整函數。

    導數：(sin z)' = cos z，(cos z)' = −sin z；sin²z + cos²z = 1 仍成立。

    和實數最大的不同：sin z、cos z 在 ℂ 上「無界」。

    |sin z|² = sin²x + sinh²y，當 |y| → ∞ 時發散。例如 cos(iy) = cosh y 可以任意大。

    零點：sin z = 0 ⇔ z = nπ；cos z = 0 ⇔ z = π/2 + nπ（只有實數零點，沒有新的零點）。

    雙曲函數：sinh z = (e^z − e^{−z})/2，cosh z = (e^z + e^{−z})/2，且 sin(iz) = i sinh z，cos(iz) = cosh z。
