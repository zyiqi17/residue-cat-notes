    公式

    留數的定義與計算公式

    定義：Res(f, z₀) = a₋₁，也就是羅朗級數中 (z − z₀)^{−1} 的係數。

    公式 1（簡單極點）：Res(f, z₀) = lim_{z→z₀} (z − z₀) f(z)。

    公式 2（p/q 型）：若 f = p/q，p(z₀) ≠ 0，q(z₀) = 0，q'(z₀) ≠ 0，則 Res = p(z₀)/q'(z₀)。

    公式 3（m 階極點）：Res(f, z₀) = (1/(m − 1)!) · lim_{z→z₀} d^{m−1}/dz^{m−1} [ (z − z₀)^m f(z) ]。

    公式 4（本性奇點）：只能直接展開羅朗級數找 a₋₁。例：Res(e^{1/z}, 0) = 1。

    例：Res(e^z / z³, 0)：e^z/z³ = 1/z³ + 1/z² + 1/(2z) + …，所以留數 = 1/2（也就是 e^z 的 z² 係數）。

    ⚠️ 常見錯誤三階極點卻只微分一次、或忘了乘 1/(m−1)!。

    高階極點的留數怎麼算？

    留數residue簡單極點高階極點留數公式p/q'
    定理

    留數定理（Residue theorem）

    若 f 在簡單封閉曲線 C（逆時針）及其內部，除了有限個孤立奇點 z₁, …, zₙ（都在 C 內部）外都解析，則

    ∮_C f(z) dz = 2πi Σ_{k=1}^{n} Res(f, z_k)。

    只算「在曲線內部」的奇點，外面的不用管。

    它是柯西定理與柯西積分公式的總整合：沒有奇點時留數和為 0，就回到柯西定理。

    例：∮_{|z|=2} e^z/(z² + 1) dz。奇點 ±i 都在圓內：

    Res(i) = e^{i}/(2i)，Res(−i) = e^{−i}/(−2i)，和 = (e^{i} − e^{−i})/(2i) = sin 1。 所以積分 = 2πi sin 1。

    留數定理怎麼用？外面的奇點要算嗎？

    留數定理residue theorem封閉曲線積分2πi乘留數和
    方法

    實積分第一型：∫₀^{2π} R(cosθ, sinθ) dθ

    代換 z = e^{iθ}，θ 從 0 到 2π 對應單位圓 |z| = 1 逆時針一圈：

    cosθ = (z + 1/z)/2，sinθ = (z − 1/z)/(2i)，dθ = dz/(iz)。

    把積分變成單位圓上的有理函數積分，再用留數定理（只算 |z| < 1 內的極點）。

    例：∫₀^{2π} dθ/(2 + cosθ)。代入後變成 ∮_{|z|=1} 2/(i(z² + 4z + 1)) dz。

    極點 z = −2 ± √3，只有 −2 + √3 在單位圓內。 Res = 2/(i(2z + 4)) 在 z = −2 + √3 = 1/(i√3)。 答案 = 2πi · 1/(i√3) = 2π/√3。

    0 到 2π 的三角函數積分要怎麼用留數算？

    三角函數積分單位圓代換z=e^{iθ}實積分
    方法

    實積分第二型：∫_{−∞}^{∞} P(x)/Q(x) dx

    條件：P, Q 為多項式，deg Q ≥ deg P + 2，且 Q 在實軸上沒有零點。

    結論：∫_{−∞}^{∞} P/Q dx = 2πi · Σ（上半平面極點的留數）。

    理由：取線段 [−R, R] 加上上半圓 C_R 圍成的封閉曲線，用 ML 不等式證明 C_R 上的積分 → 0。

    例 1：∫ dx/(x² + 1)。上半平面極點 i，Res = 1/(2i)，答案 = 2πi/(2i) = π。

    例 2：∫ dx/(x⁴ + 1)。上半平面極點 e^{iπ/4}、e^{3iπ/4}，Res = 1/(4z³) = −z/4，

    和 = −(e^{iπ/4} + e^{3iπ/4})/4 = −i√2/4，答案 = 2πi · (−i√2/4) = π/√2。

    從負無窮到正無窮的有理函數積分怎麼算？

    瑕積分有理函數積分上半平面大半圓improper integral
    方法

    實積分第三型：傅立葉型積分與 Jordan 引理

    目標：∫_{−∞}^{∞} P(x)/Q(x) · cos(ax) dx 或 sin(ax) dx，a > 0。

    做法：改算 ∫ P/Q · e^{iax} dx，再取實部（cos）或虛部（sin）。

    注意：不能直接用 cos(az)，因為 cos z 在上半平面會爆掉；e^{iaz} 在上半平面 |e^{iaz}| = e^{−ay} ≤ 1。

    條件放寬為 deg Q ≥ deg P + 1，此時用 Jordan 引理證明大半圓上的積分 → 0。

    例：∫_{−∞}^{∞} cos x/(x² + 1) dx。考慮 e^{iz}/(z² + 1)，上半平面極點 i，Res = e^{−1}/(2i)。

    ∫ e^{ix}/(x² + 1) dx = 2πi · e^{−1}/(2i) = π/e，取實部得答案 π/e。

    有 cos x 的瑕積分為什麼要換成 e^{iz}？

    傅立葉積分cos axsin axJordan引理Jordan's lemmae^{iaz}
    定理

    輻角原理與 Rouché 定理（數零點）

    輻角原理：若 f 在 C 上及內部除了有限個極點外解析，且在 C 上無零點與極點，則

    (1/2πi) ∮_C f'(z)/f(z) dz = Z − P（Z = 內部零點數、P = 極點數，都按重數計）。

    Rouché 定理：若 f, g 在 C 上及內部解析，且在 C 上 |g(z)| < |f(z)|，則 f 與 f + g 在 C 內部零點個數相同。

    口訣：「大的那個說了算」—— 把多項式拆成在曲線上「最大的項」f 和「其他項」g。

    例：z⁵ + 3z + 1。

    在 |z| = 2：取 f = z⁵，|f| = 32 > |3z + 1| ≤ 7，所以 |z| < 2 內有 5 個零點。 在 |z| = 1：取 f = 3z，|f| = 3 > |z⁵ + 1| ≤ 2，所以 |z| < 1 內有 1 個零點。 結論：1 < |z| < 2 內有 4 個零點。

    怎麼用 Rouché 定理判斷多項式在某個圓內有幾個根？

    輻角原理argument principleRouché數零點零點個數
    方法

    解題決策流程：看到 ∮_C f(z) dz 該怎麼做？

    步驟 1：找出 f 所有的奇點。

    步驟 2：判斷每個奇點在 C 的內部還是外部（畫圖！）。

    步驟 3：

    • 內部沒有奇點 → 柯西-古薩定理，答案 0。
    • f 可寫成 g(z)/(z − z₀)^{n+1}，g 在內部解析 → 柯西積分公式或高階導數公式。
    • 內部有好幾個奇點，或奇點類型複雜 → 留數定理，逐一計算留數。
    • 內部是本性奇點（如 e^{1/z}）→ 直接展開羅朗級數找 a₋₁。

    步驟 4：最後檢查方向（順時針要加負號）與 2πi 有沒有乘到。
