    定理

    泰勒級數與收斂半徑

    泰勒定理：若 f 在圓盤 |z − z₀| < R 上解析，則 f(z) = Σ_{n=0}^{∞} aₙ (z − z₀)ⁿ，其中 aₙ = f⁽ⁿ⁾(z₀)/n!。

    收斂半徑的快速判斷：等於 z₀ 到 f「最近的奇點」的距離。

    例：1/(1 + z²) 在 z₀ = 0 展開，最近的奇點是 ±i，所以收斂半徑 = 1。

    這解釋了實數的謎題：1/(1 + x²) 在實數線上處處光滑，但它的泰勒級數只在 |x| < 1 收斂，原因是複數平面上的 ±i。

    定理

    羅朗級數（Laurent series）

    若 f 在環形區域 r < |z − z₀| < R 上解析，則 f(z) = Σ_{n=−∞}^{∞} aₙ (z − z₀)ⁿ。

    負次方的部分 Σ_{n≥1} a₋ₙ (z − z₀)^{−n} 叫做主部（principal part）。

    同一個函數在「不同環形區域」有不同的羅朗級數，所以題目一定要看清楚是在哪個區域展開。

    係數 a₋₁ 就是留數 Res(f, z₀)（當 z₀ 是孤立奇點且環形區域是 0 < |z − z₀| < R 時）。

    實務上幾乎不用係數積分公式，而是用部分分式＋幾何級數來湊。

    例題

    例題：f(z) = 1/(z(z − 1)) 在不同區域的羅朗級數

    先部分分式：f(z) = 1/(z − 1) − 1/z。

    (a) 0 < |z| < 1：1/(z − 1) = −1/(1 − z) = −Σ_{n≥0} zⁿ，

    所以 f = −1/z − 1 − z − z² − …。在 z = 0 的留數 = −1。

    (b) |z| > 1：1/(z − 1) = (1/z) · 1/(1 − 1/z) = Σ_{n≥1} z^{−n}，

    所以 f = Σ_{n≥2} z^{−n} = 1/z² + 1/z³ + …（1/z 項互相抵消）。

    (c) 0 < |z − 1| < 1：令 w = z − 1，1/z = 1/(1 + w) = Σ (−1)ⁿ wⁿ，

    所以 f = 1/(z − 1) − 1 + (z − 1) − (z − 1)² + …。在 z = 1 的留數 = 1。

    重點：判斷要對 z 還是對 1/z 展開，看哪一個的絕對值小於 1。

    定義

    孤立奇點的三種分類

    看 f 在 0 < |z − z₀| < R 的羅朗級數主部：

    (1) 可去奇點：主部沒有任何項。例：sin z / z 在 z = 0（= 1 − z²/3! + …），補定義 f(0) = 1 即解析。

    (2) m 階極點：主部只有有限項，最高到 (z − z₀)^{−m}。例：1/z² 在 0 是二階極點。

    判斷法：lim_{z→z₀} (z − z₀)^m f(z) 存在且不為 0。

    (3) 本性奇點：主部有無限多項。例：e^{1/z} = Σ 1/(n! zⁿ) 在 z = 0。

    行為差異：可去 → |f| 有界；極點 → |f| → ∞；本性奇點 → 極限不存在，且根據 Casorati–Weierstrass 定理，f 在 z₀ 附近的值可以任意接近任何複數。

    性質

    零點的階數與極點的關係

    z₀ 是 g 的 m 階零點：g(z₀) = g'(z₀) = … = g⁽ᵐ⁻¹⁾(z₀) = 0，但 g⁽ᵐ⁾(z₀) ≠ 0。等價於 g(z) = (z − z₀)^m h(z)，h 解析且 h(z₀) ≠ 0。

    規則：若 p(z₀) ≠ 0 且 z₀ 是 q 的 m 階零點，則 p/q 在 z₀ 有 m 階極點。

    例：1/sin z 在 z = 0：sin 0 = 0，cos 0 = 1 ≠ 0，所以 0 是 sin z 的一階零點，1/sin z 在 0 有一階（簡單）極點。

    例：(1 − cos z)/z⁴：分子在 0 是二階零點（1 − cos z = z²/2 − …），分母四階，相減得二階極點。
