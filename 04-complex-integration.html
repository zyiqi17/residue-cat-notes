    定義

    複數路徑積分與參數化

    若曲線 C 由 z(t)，a ≤ t ≤ b 參數化，則 ∫_C f(z) dz = ∫_a^b f(z(t)) z'(t) dt。

    常用參數化：

    • 圓 |z − z₀| = r（逆時針）：z = z₀ + r e^{it}，0 ≤ t ≤ 2π，dz = i r e^{it} dt。
    • 線段從 z₁ 到 z₂：z = z₁ + t(z₂ − z₁)，0 ≤ t ≤ 1。

    方向相反時積分變號；封閉曲線預設方向是逆時針（正方向）。

    若 f 有原函數 F（F' = f），則 ∫_C f dz = F(終點) − F(起點)，與路徑無關。

    例題

    最重要的積分：∮ (z − z₀)ⁿ dz

    設 C 是以 z₀ 為圓心、半徑 r 的逆時針圓，n 為整數，則

    ∮_C (z − z₀)ⁿ dz = 2πi（當 n = −1），= 0（當 n ≠ −1）。

    推導：代入 z = z₀ + r e^{it}，得 i r^{n+1} ∫_0^{2π} e^{i(n+1)t} dt。n = −1 時被積分式為 1，得 2πi；其他情況積分一整個週期為 0。

    這就是「為什麼留數是 a₋₁」的根本原因：羅朗級數逐項積分後，只有 (z − z₀)^{−1} 那一項會留下來。

    ML 不等式（積分估計）

    若在曲線 C 上 |f(z)| ≤ M，且 C 的長度為 L，則 |∫_C f(z) dz| ≤ M L。

    用途：證明某段積分在極限下趨近 0（例如計算實積分時，大半圓上的積分 → 0）。

    例：C_R 是上半圓 |z| = R，f = 1/(z² + 1)。在 C_R 上 |z² + 1| ≥ R² − 1，所以 |f| ≤ 1/(R² − 1)，L = πR，

    |∫_{C_R} f dz| ≤ πR/(R² − 1) → 0（R → ∞）。

    估計分母時記得用反向三角不等式取「下界」。

    柯西-古薩定理（Cauchy–Goursat）與變形原理

    柯西-古薩定理：若 f 在簡單封閉曲線 C 及其內部都解析，則 ∮_C f(z) dz = 0。

    推廣：若 f 在單連通區域 D 上解析，則 D 內任何封閉曲線的積分都是 0，且 f 在 D 中有原函數。

    路徑變形原理：若 C₁ 包住 C₂（兩者同向），而 f 在兩曲線之間的環形區域（含邊界）解析，則 ∮_{C₁} f dz = ∮_{C₂} f dz。

    意義：只要不跨過奇點，就可以把積分路徑隨意「捏」成方便計算的小圓。

    ⚠️ 常見錯誤f 在曲線「內部」有奇點時（例如 1/z 在 |z| = 1 內有 z = 0），不能用柯西定理說積分為 0。

    柯西積分公式與高階導數公式

    若 f 在簡單封閉曲線 C（逆時針）及其內部解析，z₀ 在 C 內部，則

    f(z₀) = (1/2πi) ∮_C f(z)/(z − z₀) dz。

    高階導數公式：f⁽ⁿ⁾(z₀) = (n!/2πi) ∮_C f(z)/(z − z₀)^{n+1} dz。

    常用改寫：∮_C f(z)/(z − z₀)^{n+1} dz = (2πi/n!) f⁽ⁿ⁾(z₀)。

    重要推論：解析函數一定無限次可微。

    意義：解析函數在邊界上的值，就完全決定了它在內部的值。

    例題

    例題：用柯西積分公式算積分

    例 1：∮_{|z|=2} e^z/(z − 1) dz。z₀ = 1 在圓內，f(z) = e^z 解析，答案 = 2πi · f(1) = 2πi e。

    例 2：∮_{|z|=1} cos z / z³ dz。寫成 f(z)/(z − 0)^{2+1}，f = cos z，n = 2。

    答案 = (2πi/2!) f''(0) = πi · (−cos 0) = −πi。

    例 3：∮_{|z|=2} 1/(z² + 1) dz。兩個奇點 ±i 都在圓內，可用部分分式 1/(z²+1) = (1/2i)[1/(z − i) − 1/(z + i)]，得 (1/2i)(2πi − 2πi) = 0。

    解題步驟：(1) 找出被積分函數的奇點 (2) 判斷哪些在曲線內 (3) 把「解析的部分」當成 f(z) (4) 套公式。

    劉維爾定理與代數基本定理

    劉維爾定理：有界的整函數必為常數。

    證明重點：由柯西導數公式在半徑 R 的圓上估計，|f'(z₀)| ≤ M/R，讓 R → ∞ 得 f' ≡ 0。

    應用 1：sin z 是非常數整函數，所以它在 ℂ 上一定無界（和實數情況不同）。

    應用 2（代數基本定理）：次數 ≥ 1 的多項式 P(z) 至少有一個複數根。反證：若 P 無根，1/P 是整函數，且 |z| → ∞ 時 1/P → 0，因此有界，由劉維爾得 1/P 為常數，矛盾。

    定理

    最大模原理與 Morera 定理

    最大模原理：若 f 在區域 D 上解析且不是常數，則 |f(z)| 在 D 的內部取不到最大值。

    有界閉區域版本：若 f 在有界閉區域 R 上連續、在內部解析，則 |f| 的最大值一定出現在 R 的邊界上。

    例：|z² + 1| 在 |z| ≤ 1 上的最大值出現在 |z| = 1 上，取 z = ±1 得最大值 2。

    Morera 定理（柯西定理的逆定理）：若 f 在區域 D 上連續，且 D 中每條封閉曲線的積分都為 0，則 f 在 D 上解析。
