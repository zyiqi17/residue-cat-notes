# 🐱 留數喵的複變筆記

把「複變函數」整理成一張張**知識卡片**的筆記網站，用來上課複習與考前速查。

🔗 **網站：** `https://你的帳號.github.io/residue-cat-notes/`（上傳後請改成自己的網址）

## 特色

- **6 章、35 張知識卡片**：從複數基礎一路到留數定理與實積分
- 每張卡片只講一個觀念，分成 定義 / 定理 / 例題 / 方法 / 公式 / 性質 六種顏色
- 附「⚠️ 常見錯誤」與「🧠 自我檢測」問題
- 章節頁可依卡片類型篩選，左側目錄自動產生，支援手機與深色模式
- 純 HTML / CSS / JavaScript，不需要任何建置工具

## 這個專案怎麼繼續做下去？

這個專案的重點是 [`AGENTS.md`](AGENTS.md)，它規定了：

- 檔案要放在哪裡、怎麼命名
- 一張知識卡片的固定 HTML 格式
- 新增一章的 5 個步驟（複製範本 → 改頁首 → 寫卡片 → 在 `site.js` 登記 → 跑檢查清單）
- AI 修改內容時要遵守的規則（例如例題必須驗算）

只要對 AI 說一句：

> 請依照 AGENTS.md，新增第 7 章「保角映射」，包含莫比烏斯變換的定義、性質和一個例題。

AI 就能照同一套格式做出新頁面，首頁、導覽列和上一章/下一章會自動更新。

## 本機預覽

```bash
python -m http.server
# 然後打開 http://localhost:8000
```

## 檔案結構

```
index.html                 首頁
chapters/                  每一章一個頁面
assets/style.css           全站樣式
assets/site.js             章節清單與自動導覽
templates/                 新增章節用的範本
AGENTS.md / CLAUDE.md      給 AI 的專案規則
```
