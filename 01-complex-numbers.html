    定義

    複數的極式與尤拉公式

    任一非零複數 z = x + iy 都可以寫成極式 z = r(cosθ + i sinθ)，其中 r = |z| = √(x² + y²) 稱為模（modulus），θ 稱為幅角（argument）。

    尤拉公式：e^{iθ} = cosθ + i sinθ，所以極式可簡寫成 z = r e^{iθ}。

    用極式做乘除最方便：z₁z₂ = r₁r₂ e^{i(θ₁+θ₂)}，z₁/z₂ = (r₁/r₂) e^{i(θ₁−θ₂)}。也就是「模相乘、幅角相加」。

    幾何意義：乘上 e^{iα} 等於把向量逆時針旋轉 α；乘上 i 就是旋轉 90°。

    定理

    棣美弗定理與 n 次方根

    棣美弗定理：(cosθ + i sinθ)ⁿ = cos(nθ) + i sin(nθ)，n 為整數。

    求 n 次方根：若 z = r e^{iθ}，則 z 的 n 個 n 次方根為

    z^{1/n} = r^{1/n} · e^{i(θ + 2kπ)/n}，k = 0, 1, …, n−1。

    這 n 個根平均分布在半徑 r^{1/n} 的圓上，相鄰兩根夾角 2π/n，形成正 n 邊形的頂點。

    例：1 的三次方根為 1, e^{2πi/3}, e^{4πi/3}，即 1, −1/2 ± (√3/2)i。

    ⚠️ 常見錯誤只寫出 k = 0 的那一個根。n 次方根一定有 n 個（z ≠ 0 時）。

    性質

    模與共軛的性質、三角不等式

    共軛：z̄ = x − iy。常用性質：z z̄ = |z|²，Re z = (z + z̄)/2，Im z = (z − z̄)/(2i)，conj(z₁z₂) = z̄₁ z̄₂。

    模的性質：|z₁z₂| = |z₁||z₂|，|z₁/z₂| = |z₁|/|z₂|。

    三角不等式：|z₁ + z₂| ≤ |z₁| + |z₂|。

    反向三角不等式：| |z₁| − |z₂| | ≤ |z₁ − z₂|，常用來估計分母的下界，例如在 |z| = 2 上，|z² − 1| ≥ |z|² − 1 = 3。

    這個「估下界」技巧在 ML 不等式與 Rouché 定理中非常常用。

    定義

    主幅角 Arg z 與多值的 arg z

    arg z 是多值的：若 θ 是 z 的一個幅角，則 θ + 2kπ（k 為整數）也都是。

    主幅角 Arg z 規定取值在 −π < Arg z ≤ π（有些課本用 0 ≤ Arg z < 2π，考試前請確認老師用哪一種）。

    例：Arg(−1) = π，Arg(−i) = −π/2，Arg(1 + i) = π/4。

    注意：Arg(z₁z₂) 不一定等於 Arg z₁ + Arg z₂，因為相加後可能跑出 (−π, π] 的範圍。例：Arg(−1) + Arg(−1) = 2π，但 Arg(1) = 0。

    定義

    複數平面上的點集：開集、連通、區域

    ε-鄰域：{ z : |z − z₀| < ε }。

    開集：集合中每一點都有一個鄰域整個落在集合內。例如 |z| < 1 是開集，|z| ≤ 1 不是。

    連通（connected）：集合中任兩點可用落在集合內的折線連起來。

    區域（domain）：非空、開、且連通的集合。很多定理（如柯西定理、最大模原理）都要求在「區域」上成立。

    單連通（simply connected）：區域內任一簡單封閉曲線所圍內部仍在區域內，直觀上「沒有洞」。例如圓盤是單連通，環形 1 < |z| < 2 不是。
